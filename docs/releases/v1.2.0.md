# Invoice Gen v1.2.0 - macOS Foundation Release

The initial production-ready desktop release of **Invoice Gen**, introducing the core offline commercial invoice workstation for macOS.

### ✨ What's Included
* **Offline Commercial Invoice Engine**: Complete standalone invoicing workstation with zero cloud lock-in.
* **Apple macOS Disk Image (DMG)**: Packaged as a standard macOS `.dmg` container.
* **Core Invoice Ledger & Client Management**: Save, view, and organize customer invoices and client directories.
* **PDF Vector Export**: Crisp vector PDF invoice output ready for printing or emailing.
* **Built-in Calculations**: Automatic line-item subtotaling, discount math, and balance tracking.

### 📦 Release Assets
* `Invoice-Gen-1.2.0-macOS.dmg` — Standard macOS Disk Image (Universal Intel / Rosetta).
