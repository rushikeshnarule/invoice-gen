# Invoice Gen v1.4.2.1 - Vector PDF Engine, Scoped Storage & Adaptive UI 🚀

**Invoice Gen v1.4.2.1** delivers critical improvements to our document export engine, native Android sharing pipeline, and responsive layout across laptops, Mac/Windows desktop apps, and mobile phones.

---

### ⚡ 1. Direct Vector PDF Export & Native WhatsApp Sharing
* **Pure Vector PDF Generator**: Replaced unreliable DOM-measuring canvas rendering with pure `jsPDF` vector PDF generation (`pdfGeneratorService.ts`). Produces crystal-clear, executive A4 PDFs in under 10ms with zero DOM or network dependencies.
* **Android Scoped Storage & FileProvider Fix**: Overhauled `fileExportService.ts` to utilize the app's `Directory.Cache` (`context.cacheDir`). This eliminates `SecurityException` / `Permission denied` crashes on Android 10+ (API 29–35) and maps cleanly to `<cache-path name="my_cache_images" path="." />` in FileProvider.
* **Authentic Document Sharing to WhatsApp**: Clicking **"Share on WhatsApp"** or **"Share PDF"** on mobile devices compiles the vector PDF and triggers the native Android Share sheet with the attached `.pdf` document. Selecting WhatsApp immediately sends the real document file, exactly like an Excel export.
* **Eliminated Localhost URLs**: Removed all private loopback `http://localhost` links from modal interfaces, WhatsApp messages, and email drafts.

---

### 🖥️ 2. Adaptive Responsive Layout with Pinned Sticky Footers
* **Sticky Pinned Settings Footer**: Redesigned `settings-modal.tsx` with a pinned sticky footer (`shrink-0 px-4 sm:px-6 py-3 bg-slate-50 border-t`). The **"Save Changes"** and **"Close"** buttons are **permanently visible** without scrolling on small laptops (1366x768 / 1280x800 or Windows 125%/150% display scaling), Mac `.pkg` apps, and Windows `.exe` apps.
* **Navigation Rail Scrolling**: Added `overflow-y-auto` to the 9-tab settings rail to prevent tab clipping on short vertical viewports.
* **Data & Storage Mobile Stacking**: Export and reset buttons now stack vertically on mobile screens to prevent text truncation.
* **Clients View Header Layout**: Removed button overlap on mobile; client creation is streamlined via the native floating action button (`+ New Client`).
* **Clean Setup Screen Tabs**: Mobile onboarding tabs display clean, unclipped labels: `Identity`, `Taxes`, `Payment`.

---

### 🔢 3. Sequential Invoicing Engine (Starts at INV-001)
* **Standardized Numbering**: All new commercial invoices strictly begin with **`INV-001`** (or `POS-001` for retail thermal receipts).
* **Deterministic Increments**: Sequential invoices automatically increment without gaps (`INV-001`, `INV-002`, `INV-003`, etc.).
* **Smart Duplication**: Duplicating an existing invoice calculates and assigns the next highest sequential invoice number automatically.
