# Invoice Gen v1.3.0 - Template Engine & Print Engine Overhaul

Invoice Gen v1.3.0 introduces a major template architecture redesign, improved persistent storage, and dedicated print/export pipelines.

### 🚀 Key Improvements & Features
* **Live Template Customization**: Instant visual switching between invoice themes (Corporate, Minimal, POS, Slate, Excel).
* **Persistent System Storage**: Invoices, business profiles, and customer records now reliably persist through application upgrades.
* **Separated Print & PDF Export**: Distinct print rendering optimized for paper sheets and digital vector PDF export without UI clutter.
* **Enhanced Visual Themes**: Added customized high-contrast themes including thermal receipt POS layouts.
* **Performance Enhancements**: Snappy UI with immediate reactive calculations and zero render lag.
