# Invoice Gen v1.4.0 - macOS PKG Wizard, Android App & Mobile Overhaul 🚀

**Invoice Gen v1.4.0** is our most extensive cross-platform release yet! We've added native macOS PKG setup wizard installers, an official Android mobile application (`.apk`), and a complete mobile UI/UX responsiveness overhaul for on-the-go invoicing.

---

### 🍏 1. macOS Native PKG Wizard Installer
* **One-Click Native Setup Wizard**: Replaced manual drag-and-drop `.dmg` mounting with standard macOS `.pkg` installer packages.
* **Native Apple Silicon M-Series Support**: Dedicated `arm64` package targeting Apple Silicon (M1, M2, M3, M4) alongside universal Intel `x64` builds.
* **Direct `/Applications` Destination**: Automatically installs `Invoice Gen.app` directly into macOS Applications folder with complete application icons.
* **Automated Cloud Workflows**: Automated GitHub Actions runners compile genuine macOS binaries with icon bundles and code-signing readiness.

---

### 📱 2. Native Android APK Application
* **Capacitor 7 Integration**: Native Android mobile wrapper delivering 100% of all workstation features, business logic, calculations, and PDF generation offline.
* **Offline-First Storage**: Invoices, customer directories, and tax preferences persist directly to mobile local storage.
* **Adaptive Multi-Density Launcher Icons**: Rendered sharp launcher icons across all screen densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`).
* **Automated APK Builder**: Fully configured CI/CD pipeline compiling installable release `.apk` binaries.

---

### 🎨 3. Mobile Responsiveness & Touch Ergonomics Overhaul
* **Native Mobile Bottom Navigation**:
  * On mobile viewports (`<md`), the desktop floating sidebar seamlessly switches to a thumb-friendly bottom navigation bar.
  * Real-time badges for active invoices and template counts.
  * Native touch active indicators with haptic-feel transitions.
* **Adaptive Invoice Editor (Mobile vs Desktop)**:
  * Intelligent segmented toggle:
    * `✍️ Edit Invoice`: Full-screen touch-optimized form with enlarged touch targets.
    * `👁️ Live Preview`: Auto-scaled, edge-to-edge invoice document preview.
  * Preserved full side-by-side workstation layout on desktop displays.
* **Responsive Invoice Ledger & Rows**:
  * Transformed desktop data tables into sleek adaptive mobile cards.
  * Clean layout separating client name, invoice number, status chips, amount due, and quick-action toolbars.
* **Touch & Safe-Area Optimization**:
  * Modern viewport handling with `viewport-fit=cover` and `user-scalable=no`.
  * Safe-area insets (`safe-area-bottom`, `safe-area-top`) for notched mobile screens.
  * Smooth horizontal scrollbars for toolbar items.
  * Form inputs styled to eliminate mobile WebView auto-zooming quirks.

### 🛠️ Installation Instructions

#### Windows
1. Download `Invoice-Gen-Setup-1.4.0.exe`.
2. Double-click to install. If Windows SmartScreen prompts "Windows protected your PC", click **More info** -> **Run anyway**.

#### macOS
1. Download `Invoice-Gen-Setup-1.4.0-arm64.pkg` (for Apple Silicon) or `Invoice-Gen-Setup-1.4.0-x64.pkg` (for Intel).
2. Double-click to launch the native macOS Setup Wizard.
3. If macOS displays a developer verification prompt:
   - Right-click (or Control-click) `Invoice Gen.app` in `/Applications` and select **Open**.
   - Or open Terminal and run:
     ```bash
     xattr -cr "/Applications/Invoice Gen.app"
     ```

#### Android
1. Download `Invoice-Gen-1.4.0.apk` to your phone or tablet.
2. Tap the APK to install.
3. If prompted, toggle **Allow installation from unknown sources** for your browser or file manager.
