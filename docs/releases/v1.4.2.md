# Invoice Gen v1.4.2 - Dynamic Versioning & Resilient Auto-Update Engine 🚀

**Invoice Gen v1.4.2** brings critical architectural enhancements to our version tracking and auto-update infrastructure, resolving version mismatch bugs and ensuring reliable update telemetry across all platforms.

---

### ⚡ 1. Dynamic Runtime Version Resolution
* **Accurate Version Detection**: Eliminated hardcoded version strings across the frontend, service layer, and React contexts. The app dynamically queries `window.invoiceDesktop.appVersion` (Electron native runtime) with automatic fallback to Vite build-time `__APP_VERSION__` from `package.json`.
* **Zero Post-Install Version Lag**: Upgrading to a new release immediately reflects the correct version number in Settings, the top update banner, and system diagnostic headers.
* **Synchronized Application State**: `InvoiceContext` and local storage schema track the exact active software version.

---

### 🛡️ 2. Resilient Auto-Update Engine (CSP & Native IPC Fix)
* **Native Desktop IPC Update Bridge**: Update queries now execute via Node.js native `https` module (`desktop:check-updates`), completely bypassing browser Chromium sandbox, CSP headers, and CORS restrictions.
* **Eliminated "Failed to fetch" Error**: Fixed network exceptions when querying GitHub release API from packaged desktop binaries.
* **Expanded Content Security Policy**: Added official GitHub API and content distribution domains (`api.github.com`, `objects.githubusercontent.com`) to `index.html` and the loopback Express server.
* **Automatic Status Synchronization**: Entering **Settings ➔ Software Updates** automatically evaluates the latest release and displays an instant "You're up to date!" confirmation badge.

### 🛠️ Installation Instructions

#### Automatic In-App Update (Recommended)
1. Open Invoice Gen.
2. If an update is available, click **Update Now** on the top notification banner, or navigate to **Settings ➔ Software Updates** and click **Download & Install**.
3. The app will download the update package with live progress and automatically launch the installer.

#### Manual Installation
* **Windows**: Run `Invoice-Gen-Setup-1.4.2.exe`.
* **macOS**: Double-click `Invoice-Gen-Setup-1.4.2-arm64.pkg` (Apple Silicon) or `Invoice-Gen-Setup-1.4.2-x64.pkg` (Intel).
* **Android**: Download and tap `Invoice-Gen-1.4.2.apk` to install on your Android device.
