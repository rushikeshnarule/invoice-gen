# Invoice Gen v1.5.0 - Seamless Hot Updates, Full SAST Hardening & Physical Android Mobile Audit 🚀

**Invoice Gen v1.5.0** is a major milestone release delivering enterprise-grade Static Application Security Testing (SAST) compliance, zero high-severity supply chain vulnerabilities, seamless in-app hot-updating without setup wizard loops, physical hardware validation on OnePlus 8T, and statutory sequential invoice numbering starting with `INV-001`.

---

### ⚡ 1. Seamless In-App Hot Updates (Zero Setup Wizard)
* **Direct `.asar` Binary Hot-Swap**: Resolved the issue where clicking "Update" re-downloaded the installer and forced users to manually click through setup screens again.
* **In-Place Application Reload**: On Windows and macOS desktop workstations, Invoice Gen downloads the lightweight in-app update package (`Invoice-Gen-Update-1.5.0.asar`, ~31 MB) and hot-swaps the runtime files in the background, relaunching straight into the updated software while keeping all Documents databases and settings untouched.
* **Silent NSIS / PKG Execution**: For full installer binaries, Windows executes silently (`/S`) and macOS invokes background `/bin/bash` scripts to restart the bundle cleanly.

---

### 🛡️ 2. Static Application Security Testing (SAST) & Supply-Chain Hardening
* **Zero High / Critical CVEs**: Completely pruned vulnerable legacy SheetJS packages (`xlsx` and `xlsx-js-style` carrying CWE-1321 Prototype Pollution and CWE-400 ReDoS). Migrated all tests and Excel exports strictly to modern `ExcelJS 4.4.0`.
* **Insecure IPC Execution Guard (CWE-78 & CWE-426)**: Implemented in-memory validation tokens (`validDownloadedUpdates`) and verified temporary path containment (`app.getPath('temp')`) in `electron/main.cjs` so only binaries verified by the update service can be executed.
* **SSRF Prevention (CWE-918)**: Added `isTrustedDownloadUrl()` enforcing strict HTTPS and verified GitHub/AWS release host domains across initial queries and multi-hop redirects.
* **Prototype Pollution Immunity (CWE-1321)**: Embedded `safeJsonParse()` revivers across local system storage endpoints (`/api/system-storage`), recursively stripping `__proto__`, `constructor`, and `prototype` keys during JSON deserialization.
* **Content & URI Sanitization**: Neutralized `@import` and `javascript:` expressions in remote CSS themes; enforced `noopener,noreferrer` on all `window.open` external targets.

---

### 📱 3. Physical Hardware Android Validation (OnePlus 8T)
* **Real Device Tested**: Validated on physical OnePlus 8T (`KB2001`, Android 14) connected via USB tethering/debugging.
* **Responsive Segmented Controls**: Fixed tab label collisions on narrow smartphone screens by implementing horizontal smooth scrolling (`overflow-x-auto [scrollbar-width:none] min-w-max`).
* **Android Scoped Storage & FileProvider**: Binary `.pdf` and `.xlsx` documents are written to Cache and shared directly via `Intent.ACTION_CHOOSER`, eliminating broken `http://localhost/...` links.
* **Root Application Crash Isolation**: Integrated an `ErrorBoundary` that isolates component failures and protects active unsaved invoice data.

---

### 🔢 4. Strict Sequential Numbering (Starts at `INV-001`)
* Commercial invoices systematically default to and increment sequentially from **`INV-001`** (`INV-001`, `INV-002`, `INV-003`, etc.).
