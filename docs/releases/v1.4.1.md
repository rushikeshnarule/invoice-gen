# Invoice Gen v1.4.1 - In-App Seamless Auto-Updater & Performance Overhaul 🚀

**Invoice Gen v1.4.1** introduces our native in-app auto-update engine! Users can now download and automatically install software updates directly within the application without opening external web browsers or manually downloading files.

---

### ⚡ 1. Direct In-App Auto-Update Engine
* **Seamless In-App Downloader**: Download new update packages straight within the desktop application with zero external redirects.
* **Live Telemetry & Progress**: Real-time progress bar with percentage, downloaded megabytes, total file size, and dynamic transfer speed (MB/s).
* **Automatic Silent Installation**: Once the package download finishes, the installer launches automatically and restarts the workstation with the updated version.
* **Smart Failure Recovery**: Automatic retry mechanism and fallback to browser download if network interruptions occur.

---

### 🛠️ 2. Updates Hub in Settings & Command Palette
* **Dedicated Settings Tab**: Access **Settings ➔ Software Updates** to view current version health, check for updates, and toggle automatic startup checks.
* **Command Palette Integration**: Press `Ctrl+K` (or `⌘K` on Mac) and hit `U` or search "Check for Software Updates" to verify release status from anywhere.
* **Adaptive Platform Detection**: Automatically detects Windows (x64), macOS (Apple Silicon & Intel), Android, and Web environments.

### 🛠️ Installation Instructions

#### Automatic In-App Update (Recommended)
1. Open Invoice Gen.
2. Click **Update Now** on the top notification banner, or go to **Settings ➔ Software Updates** and click **Download & Install**.
3. The app will download the update package and launch the installer automatically.

#### Manual Installation
* **Windows**: Run `Invoice-Gen-Setup-1.4.1.exe`. If Windows SmartScreen prompts, click **More info** -> **Run anyway**.
* **macOS**: Double-click `Invoice-Gen-Setup-1.4.1-arm64.pkg` (Apple Silicon) or `Invoice-Gen-Setup-1.4.1-x64.pkg` (Intel).
* **Android**: Download and tap `Invoice-Gen-1.4.1.apk` to install.
